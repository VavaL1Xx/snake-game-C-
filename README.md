Классическая игра "Змейка", которую можно запустить в терминале Windows, написанная на C++. Игра поддерживает настройку размеров игрового поля, скорости, цветовой схемы и символов отрисовки через параметры командной строки.


### ✨ Особенности
- Цветная графика — полноцветная отрисовка в консоли Windows с настраиваемыми цветами змеи, еды и границ
- Гибкая настройка — изменяйте размер поля, начальную скорость и символы через параметры запуска
- Динамическая сложность — скорость игры увеличивается каждые 10 очков
- Удобное управление — стрелки, WASD или русская раскладка (ЦФЫВ)
- Статистика в реальном времени — отображение счёта, длины змеи и текущей скорости
- Игровые команды — пауза (SPACE) и быстрый выход (ESC)

### 🎮 Управление (Действие -	Клавиши)

| Действие | Клавиши   |
| -------- | --------- |
| Вверх    | ↑ / W / Ц |
| Вниз     | ↓ / S / Ы |
| Влево    | ← / A / Ф |
| Вправо   | → / D / В |
| Пауза    | SPACE     |
| Выход    | ESC       |

## 🚀 Как запустить

Вариант 1: Компиляция через Visual Studio Клонируйте репозиторий:

```bash
git clone https://github.com/vavlxxx/Snake-In-Console.git
cd Snake-In-Console
```
Откройте файл .sln в Visual Studio, нажмите F5 или выберите Build -> Build Solution. Запустите игру из Debug или Release папки
​
Вариант 2: Компиляция через MinGW/g++
```bash
g++ -o snake.exe main.cpp game.cpp block.cpp
snake.exe
```

## 🎯 Примеры запуска с параметрами

Базовый запуск (стандартные настройки) - Размер: 32×16, скорость: 10, зелёная змея, красная еда, синие границы
```bash
snake.exe
```

Кастомная цветовая схема. Жёлтая змея, фиолетовая еда, голубые границы и просторное поле 50×25

```bash
snake.exe -sncol 14 -fdcol 5 -bdcol 3 -w 50 -h 25
```

| Параметр | Описание                              | Значение по умолчанию |
| -------- | ------------------------------------- | --------------------- |
| -w       | Ширина игрового поля                  | 32                    |
| -h       | Высота игрового поля                  | 16                    |
| -freq    | Начальная скорость (кадров в секунду) | 10                    |
| -sncol   | Цвет змеи (1-15)                      | 2 (зелёный)           |
| -fdcol   | Цвет еды (1-15)                       | 4 (красный)           |
| -bdcol   | Цвет границ (1-15)                    | 1 (синий)             |
| -symb    | Символ для отрисовки                  | █ (char 219)          |
| -help    | Показать справку                      | —                     |

Коды цветов в консоли Windows Console

- 1 — Синий
- 2 — Зелёный
- 3 — Голубой
- 4 — Красный
- 5 — Фиолетовый
- 7 — Белый
14 — Жёлтый
